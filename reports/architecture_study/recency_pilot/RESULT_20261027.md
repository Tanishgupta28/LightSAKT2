## Next architectural hypothesis: normalized decayed ELU+1 attention

Evidence: the ELU+1 kernel still beats both softmax variants; adding recency to
softmax recovered+0.002598410 AUC on this seed. This motivates testing the
recency factor while retaining the stronger kernel, rather than changing depth
or replacing the kernel again. This is a hypothesis, not measured improvement.
The original25October study already mentioned decayed linear attention, but no
implementation/config/run for it is present in the current attention/model tree.
Source inspection confirms existing linear attention uses undecayed prefix K/KV
sums and normalizes numerator and denominator over the same history.

Proposed isolated change, per head, with phi(x)=ELU(x)+1:
S_t=lambda*S_(t-1)+phi(k_t)*v_t^T;
z_t=lambda*z_(t-1)+phi(k_t);
y_t=phi(q_t)^T*S_t/(phi(q_t)^T*z_t+1e-8).
Use lambda=exp(-softplus(a_head)), initially exp(-1/32), with one scalar per head.
Decay both states identically; mask key contributions and queries. Keep padding
index-distance semantics consistent with this recency arm and keep all embeddings,
projections, residuals/norms/FFN/head and training controls frozen.
At lambda=1, this reduces mathematically to the existing normalized prefix kernel.

Before any new training: implement separately, compare dense weighted-prefix and
recurrent/scan outputs plus gradients, check lambda=1 baseline equivalence,
causality/padding/finite gradients/determinism, and numerical stability without
inverse powers. A dense reference is quadratic and must not be reported as a
linear-time implementation. Do not silently replace the protected baseline.
Then request one separately bounded ASSIST2009 seed42 validation-only pilot;
only promote to five seeds42/123/2026/3407/7777 on all three datasets after a
credible baseline-relative screening gain. No such additional run is authorized
or launched in the current task.

Primary-source motivation, reviewed27October2026: [AKT](https://arxiv.org/abs/2007.12324)
uses exponential decay with context-aware distance in KT. [RetNet](https://arxiv.org/html/2307.08621v4)
section2 shows recurrent decay-weighted KV states and parallel equivalents.
Neither paper proves that the proposed normalized ELU+1 transplant will improve
this benchmark; it is not a reproduction of either full architecture.
