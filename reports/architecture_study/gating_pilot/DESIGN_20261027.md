# Frozen gated-linear experiment design — 27 October 2026

Hypothesis: a target-skill-conditioned scalar gate can regulate historical
attention contribution while retaining the strongest observed attention kernel.
This is an untested hypothesis; no performance claim at preparation time.

For next-skill embedding e_t and original projected linear-attention output a_t:
g_t=2*sigmoid(w_g*e_t+b_g), s_t=LayerNorm(Dropout(g_t*a_t)+m_t+e_t).
Only gate65parameters are new at d64; w_g,b_g zero initialized so g_t=1.
Range0..2 permits suppression or amplification with stable sigmoid. No extra
initialization RNG is consumed. Original parameters and dropout-active forward
path exactly match at initialization. It is a query-conditioned scalar, not a
channel-wise matrix gate. Gate multiplies the entire attention branch including
its projection bias before the unchanged output dropout. Raw visualization
weights continue to describe the ungated normalized kernel.

One block, causal ELU+1 attention, m/e residual, positions, LayerNorms, FFN and
prediction head unchanged. No extra decay, probability dropout, depth or tuning.
Known target skill only conditions the gate, not any unseen response. Original
LightSAKT source is protected; new model/factory name LightSAKTGated.

ASSIST2009,seed42,L100,d64,2heads,dropout0.1,batch64,Adam lr0.001,
betas(0.9,0.999),epsilon1e-8,weight decay0,50epochs,patience5,
strict pooled validation-AUC checkpointing,float32,no AMP/TF32. Existing
student splits/vocabulary fixed. No test evaluation; no baseline rerun.
